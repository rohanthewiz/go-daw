# Session: Sustain Pedal (CC64) + GM Drums Toggle

- **Session ID**: `c3b661c7-3cb1-4c89-bef8-7e459434e481`
- **Date**: 2026-07-31
- **Branch**: main

## Goal

Picked from a low-hanging-fruit survey: (1) sustain pedal via space bar and
MIDI CC64 for both playable synths, (2) a live GM drums toggle for the
SoundFont source. Item (3) — velocity from mouse position — was found to be
**already implemented** (`velFromEvent` in `web/assets/app.js` maps click
height on a key to velocity), so no work was needed.

## Sustain pedal

### New: `source.Sustainer` interface (`audio/source/source.go`)

`Sustain(down bool)` — deliberately separate from `NotePlayer` so an
instrument without pedal semantics can still be playable; handlers
feature-detect with a type assertion.

### `SFSynth` (`audio/source/soundfont.go`)

- New ring event `evPedal = 1 << 10` (bit 0 = down). Drain sends MIDI CC64
  (`ProcessMidiMessage(0, 0xB0, 64, 127|0)`); meltysynth honors hold-pedal
  natively (voice release is deferred while `holdPedal` is set — verified in
  its source).
- Pedal targets the melodic channel only: GM percussion is one-shot by
  convention, sustaining it would just smear cymbal tails.

### `PolySynth` (`audio/source/polysynth.go`)

Real damper semantics, since this synth has no CC concept:

- New ring event `synthEvPedal = 1 << 9` (bit 9 is free in packNote's layout).
- Audio-thread `pedalDown bool`; per-voice `sustained bool`.
- Key-off while pedal down → voice marked `sustained`, keeps its **natural
  decay** (stays in attack/decay state). Pedal-up → all sustained voices enter
  release. Re-struck/stolen voices clear `sustained`.

### Web plumbing

- `POST /api/channel/:id/pedal` `{down: bool}` (`web/handlers.go`,
  `web/server.go`). 409 when the source isn't a `Sustainer`, mirroring the
  note handler's "state conflict, not bad request" convention.
- `app.js`: space bar = pedal (keydown/keyup, `preventDefault` stops page
  scroll and focused-button re-click; `isTypingTarget` guard applies).
  `pedalSet()` dedupes transitions client-side (space autorepeats, MIDI pedals
  stream continuous values). Hardware CC64 forwarded with the standard ≥64
  threshold. `midiPanic()` now lifts the pedal too (unplugged pedal can never
  send its own release).
- Piano hint text updated: "Space sustain".

## GM drums toggle

### `SFSynth`

- New ring event `evDrums = 1 << 11` (bit 0 = on). Drain calls
  `synth.NoteOffAll(false)` (natural tails, not hard cut) **before** flipping
  the audio-thread `drumsOn` switch — a channel switch mid-hold would
  otherwise send note-offs to the wrong channel and strand notes.
- Note events route to MIDI channel 9 (meltysynth pins it to the bank's
  percussion presets) when on, channel 0 otherwise.
- `SetDrums/Drums` with an atomic mirror for snapshots/UI, same pattern as
  `program`. Program changes always go to channel 0 (percussion presets are
  keyed by note, not program).

### Wiring

- `sfont.drums` live source-param (no rebuild/reload — same class as program
  changes) in `sourceParamHandler`.
- Scene persistence: `SourceState.Drums bool` (`drums,omitempty`); captured in
  `captureSource`, restored in `SetChannelSource` via `SetDrums(true)` after
  construction (queued event drains on first `Read`, before any note).
- UI: "Drums" checkbox on the sfont strip (`toggle()` helper, target `src`) —
  the generic checkbox→sendParam path needed zero new JS.

- Pedal down → chord → pedal up: all 200.
- Drums on → snare/kick/hat: real signal, ch 4 meter peak ≈ −26 dBFS via SSE.
- Drums flag round-trips scene save → toggle off → recall → back on.
- Pedal on oscillator channel → 409 as designed.

## Notes / future ideas

- Drum kit selection: program change on channel 9 would select among a bank's
  drum kits (GeneralUser GS has several at bank 128) — UI currently shows
  melodic GM names, so this was deliberately skipped.
- Keyboard octave: GM kit lives at notes 35–81; press Z a couple times to
  reach kick/snare/hat (36/38/42) from the default C4 base.
- Sostenuto (CC66) and soft pedal (CC67) would follow the same evPedal
  pattern if ever wanted; meltysynth doesn't implement CC66.
