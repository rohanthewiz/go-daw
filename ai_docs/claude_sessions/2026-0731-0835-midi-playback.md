## New source: `MidiPlayer` (`audio/source/midiplayer.go`)

- Bank (`.sf2`) and song (`.mid`) both parsed **at construction** on the
  control plane; a bank/song change rebuilds the source (wav/sfont-bank
  convention). Banks come from the shared `bankCache`, so a song channel and a
  live sfont channel on the same bank cost one copy of the sample data.
- Transport commands ride a 16-slot lock-free ring (`midiEvPlay/Pause/Stop` as
  plain enums — mutually exclusive, no bit flags needed). Verified against
  meltysynth source: `seq.Play` (→ `synth.Reset`), `seq.Stop`, `seq.Render`,
  `processEvents` are all alloc/lock-free — realtime contract holds.
- **State machine** (audio-thread-owned; `state` atomic is a single-writer
  mirror the control plane only reads):
  - play on stopped → `seq.Play(file, loop)` from top; play on paused →
    resume (sequencer clock/index survive the pause untouched).
  - pause → `NoteOffAll(false)` (hands-off-keys, not power-cord) then render
    `synth.Render` directly each block so tails decay while the song clock
    freezes.
  - stop → `seq.Stop()` (synth reset, immediate silence), pos → 0.
  - **Auto-stop**: non-loop playback flips itself to stopped after song length
    + 2 s tail (`midiTailSeconds`) so the UI never shows "playing" over
    silence forever.
- **Loop caveat**: the sequencer latches its loop flag only at `Play` time
  (private field), so `SetLoop` is a control-plane atomic read by the drain
  when a play event lands — mid-song toggles apply on next play.
- Position: `posFrames` atomic accumulated per block; `PosSeconds()` folds by
  song length when looping (sequencer clock is private), clamps to length at
  the tail. Stopped `Read` returns 0 (engine zero-fills) — no render cost.

## Wiring

- **Scene state** (`mixer/state.go`): `SourceState` gained `Bank` (midi's
  `.sf2`) and `Loop`; `Path` reused for the `.mid`. Type `"midi"`. Capture
  saves bank/path/loop/level (transport position is performance state, not
  scene-worthy). Restore builds stopped — recall never auto-blasts — and
  default level −6 dBFS (same rationale as sfont).
- **Config**: `MidiDir` (default `midifiles`); config.json untouched —
  it relies on defaults exactly as `soundbanksDir` does.
- **Web** (`handlers.go`, `server.go`):
  - `listMidiFiles()` scans `.mid`/`.midi` per render; `GET /api/midifiles`.
  - `POST /api/channel/:id/midi` `{action: "play"|"pause"|"stop"}` —
    dedicated endpoint (discrete ordered events, not debounced values); 409
    on non-midi source, 400 on unknown action.
  - source-params: `midi.level`, `midi.loop` (live).
  - **SSE**: meterLoop broadcasts `midi: [{state,pos,len}|null,…]` aligned
    with channel index, omitted entirely when no channel has a player. The
    ~12.5 Hz meter cadence doubles as the position-readout rate.

## UI

- `channelstrip.go`: `midi` option in the source select (disabled unless ≥1
  bank AND ≥1 song exist — disable-to-advertise); `.src-midi` row = bank +
  song selects (both structural → rebuild+reload), ▶ ⏸ ⏹ transport buttons,
  `m:ss / m:ss` readout (server renders initial value via `fmtClock`),
  level slider + Loop toggle (generic sendParam path, zero new JS for them).
- `app.js`: transport clicks POST the action; button highlight comes from the
  SSE state (no optimistic toggling → buttons always show real state);
  `clock()` mirrors fmtClock. Styles: play button glows green when playing,
  pause amber when paused (hex dims of the existing `green`/`amber` vars).

## Tests (all green: build/vet/full suite)

`midiplayer_test.go` uses a **hand-assembled format-0 SMF** (one 0.5 s
middle-C note, 480 tpq @ 120 BPM) written to a temp dir — exact timeline, no
MIDI-writer dep. Reuses `testBank(t)` skip-if-absent convention.

- PlayStop — silence→audio→stop; stopped Read returns 0 (the contract's
  silence signal; don't inspect stale buffers — first version of the test
  did and failed).
- PauseResume — position frozen across paused blocks, resume continues.
- AutoStop — stopped state after song+tail (~520 blocks).
- Loop — audio still present at ~3 s, state playing, pos folded ≤ length.
- ReadNoAllocs — `Play` + `Read` per iteration covers seq.Play/Reset drain.
