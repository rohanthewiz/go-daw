# MIDI files

Drop Standard MIDI Files (`.mid` / `.midi`, format 0 or 1) in this folder and
they appear in each channel's **midi** source selector on the next page reload
— no restart needed. Pick a SoundFont bank and a song on a channel, then use
the ▶ ⏸ ⏹ transport in the strip.

`demo.mid` (8 bars, C–G–Am–F, piano + bass + drums) was generated by
`arch_test_scripts/genmidi/main.go`.
